# Student Tracker - Quản Lý Học Sinh & Xếp Loại

Dự án bài thi ứng viên Python - TEKY: Hệ thống quản lý học sinh, tính điểm trung bình (ĐTB), xếp loại học lực và tìm kiếm học sinh với kiến trúc hướng đối tượng (OOP) và giao diện dòng lệnh (CLI).

## Cách khởi chạy

### 1. Kích hoạt môi trường ảo
```powershell
.\.venv\Scripts\Activate.ps1
```

### 2. Chạy ứng dụng CLI
```bash
python main.py
```
